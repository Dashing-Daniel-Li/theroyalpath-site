Royal Path Uploader

Privacy policyYouTube channel

Royal Path Uploader is a small, private script used only by the owner of The Royal Path YouTube channel. It is not a public app and has no other users.

What it does

  • Uploads the channel’s own videos, which we produce ourselves.
  • Sets each video’s title, description, tags and scheduled publish time.
  • Adds videos to the channel’s own playlists.

How it uses YouTube

It uses the YouTube Data API v3 through the channel owner’s own Google sign-in (OAuth). It only ever accesses our own channel, and it does not read, collect or display anyone else’s data.

By using YouTube, the channel is bound by the YouTube Terms of Service.
